# 动手练习册（自己从头练一遍）

> ## 这一本和别的文档不一样：**答案都不在本页**
>
> `上手路线.md` / `问题记录.md` / `面试速查.md` 都是**查阅型**的 ——
> 它们回答「是什么」。读它们能让你**查得到**，但**不会让你会**。
>
> 能力只来自一个动作：**在不知道答案的时候先猜，然后被打脸。**
> 我（AI）已经跑过的那些实验，结论全在文档里了 ——
> **照着做一遍学不到东西**，因为你已经知道答案了。
> 所以第 4、5 关用的是**不同的参数**，你没法靠记忆，只能真预测。
>
> **这一本就是为了制造「被打脸」。**

---

## 铁律

| # | 铁律 | 为什么 |
| --- | --- | --- |
| 1 | **先写预测，再敲命令** | 预测错了才是学到东西的那一刻；预测对了只是确认 |
| 2 | **不许先看答案** | 答案都在「答案在哪」指向的地方，做完再去对照 |
| 3 | **错了要记一笔**：我原以为 ____，实际是 ____，因为 ____ | 这一步比做题本身重要 |
| 4 | **不要开着文档敲命令** | 那会变成抄命令。卡住 5 分钟再去查 |
| 5 | **一次只练一关** | 一天练完五关 = 什么都没留下 |

## 判分（自己给自己打）

对**还没见过的改动**写预测：

| 预测命中率 | 说明 |
| --- | --- |
| < 30% | 还停在「看懂了」阶段 —— 把对应那关重做一遍 |
| 50% 左右 | 正常水平，**继续，别急** |
| > 70% | 真的会了，可以去改代码了 |

> ⚠️ **记住结论 ≠ 会做预测。**
> 你能背出「膨胀半径调大 → 路径变长」，不代表你能预测
> 「把 `cost_scaling_factor` 从 3.0 调到 1.0 会怎样」。
> 练习册里的参数故意和文档里的不一样，就是为了卡住「靠记忆」这条路。

## 第 4 关 · L4「能改对」—— **本关参数故意和文档不同**（约 90 min）

> ⚠️ 这一关最重要的不是「改对」，是**先写预测**。
> 文档里我做过的是 0.55→**1.2**、0.26→**0.45**、雷达 10→**15** Hz。
> **下面用的是别的值。** 你没法靠记忆，只能真预测。

### 4-0 先学会「不改源码地改参数」

**先预测**：为什么不建议直接改 `config/nav2_params.yaml` 来做实验？
（两个理由）

**答案在哪**：`docs/详情-nav2_params.md` 的调试入口；本项目所有实验都走
`params_file:=/tmp/xxx.yaml`

**固定套路**（这个可以直接抄，因为它是**手法**不是**结论**）：

```bash
# 1) 在容器里复制一份到 /tmp（注意：不要改源码那份）
./scripts/shell.sh -c 'cp /workspace/my-slam/src/navigation/mybot_navigation2/config/nav2_params.yaml /tmp/tune.yaml'

# 2) 在 /tmp/tune.yaml 上做替换
./scripts/shell.sh -c 'sed -i "s/原值/新值/" /tmp/tune.yaml && grep -n "新值" /tmp/tune.yaml'

# 3) 用覆盖参数重启 Nav2，并立刻设初始位姿（60 秒窗口！）
./scripts/stop-nav2.sh
nohup ./scripts/shell.sh -c "exec ros2 launch mybot_navigation2 navigation2.launch.py rviz:=false params_file:=/tmp/tune.yaml" > /tmp/nav2_t.log 2>&1 &
sleep 27
./scripts/shell.sh -c 'python3 tools/set_initial_pose.py --from-gz'

# 4) 量 …… 然后务必还原
./scripts/stop-nav2.sh && ./scripts/shell.sh -c 'rm -f /tmp/tune.yaml'
```

### 4-1 膨胀半径：0.55 → **0.35**（是调小，不是调大）

**先预测**（三问全答，**写下来**）：

| 问题 | 我的预测 |
| --- | --- |
| 路径会变长还是变短？ | |
| 沿途**最高**导航代价会升还是降？ | |
| 目标可达性会变吗？（同一个目标） | |
| 「能不能过门」会变吗？ | |

**做**：按 4-0 的套路改 `inflation_radius`，然后

```bash

```

**答案在哪**：`问题记录.md` **E-20 改动 2**（那是 0.55→1.2 的实测）和 **E-22**

**这一题的真正考点**：你能从「**调大**」的规律**推导**出「**调小**」的规律吗？
能推导出来，说明你理解了机制；只能背住现象，说明还差一层。

## 常见陷阱

| 陷阱 | 为什么会这样 | 怎么办 |
| --- | --- | --- |
| 边看文档边敲 → 变成抄命令 | 舒服、有安全感 | 把文档关掉；卡住 5 分钟再去查 |
| 预测错了直接看答案 → 跳过最重要的那步 | 想知道答案的冲动 | 先写「我原以为…」，再翻 |
| 一天练完五关 | 以为效率高 | 分 3 天。记忆需要**间隔** |
| 只求跑通、不看数字 | 「跑通了」有完成感 | 每个数字都要能说出**来源** |
| 「这几题我已经知道答案了」→ 跳过 | 真的知道了 | **换个参数**再测一遍（见第 4 关开头）|
